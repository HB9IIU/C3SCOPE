# C3SCOPE modifications

As of 27 October 2026, HB9IIU's C3SCOPE adapts the ESPARGOS ESP-WebSDR
viewer with C3SCOPE branding, a Flask/pyserial transport, automatic receiver
discovery, guided firmware installation, application lifecycle controls,
LAN viewing, display defaults, and experimental DATV estimates and markers.

The upstream viewer's GPL-3.0-or-later licence and existing notices are
preserved. Original C3SCOPE code is also GPL-3.0-or-later; see COPYING.md
and LICENSE. See THIRD_PARTY.md for component provenance.
